# Extensions Seanime

Extensions pour [Seanime](https://seanime.app).

## MangaMoins + Anime-Sama

Scans de manga en français. Les chapitres viennent de [MangaMoins](https://mangamoins.com) ; ceux qui n'y sont pas (anciens chapitres, séries absentes) sont complétés par [Anime-Sama](https://anime-sama.to). Les chapitres spéciaux d'Anime-Sama (0, x.5, One Shot…) sont placés au bon endroit sans décaler la numérotation.

### Installation

Dans Seanime : **Extensions → Ajouter une extension**, puis colle :

```
https://raw.githubusercontent.com/NOUSSS/seanime-extensions/main/mangamoins/manifest.json
```
