# MangaMoins + Anime-Sama

Fournisseur de scans FR pour Seanime.

- Tous les chapitres présents sur MangaMoins sont pris en priorité.
- Les numéros absents de MangaMoins, et les séries qu'il n'a pas, viennent d'Anime-Sama.
- Chaque chapitre indique sa source (champ « scanlator »).

Manifest : `https://raw.githubusercontent.com/NOUSSS/seanime-extensions/main/mangamoins/manifest.json`
